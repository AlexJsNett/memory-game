# Memory Game

Игра на поиск пар для задания RS School. 16 карточек, 8 пар: открывайте карточки по две и находите совпадения за наименьшее число ходов.

**Deploy:** https://alexjsnett.github.io/memory-game/

## Возможности

- Поле 4×4, карточки перемешиваются (Fisher–Yates) при загрузке и в каждой новой игре.
- Счётчики ходов и найденных пар.
- Несовпавшая пара закрывается через 1 секунду, пока она открыта, остальные карточки заблокированы.
- Модальное окно победы с числом ходов.
- Таблица лидеров: топ-10 результатов в `localStorage` (место, ходы, дата `ДД.ММ.ГГГГ`).
- Кнопка «Новая игра» работает в любой момент и сразу отменяет таймер несовпавшей пары.
- Модальные окна закрываются кнопкой, кликом по фону или клавишей Escape.

## Технологии

HTML, CSS и JavaScript (ES modules), без библиотек и фреймворков. Вся разметка создаётся через `document.createElement` (`src/dom.js`), в `<body>` только `<script>`.

## Структура

```
index.html            пустой body + script
src/main.js           сборка приложения
src/dom.js            обёртка над document.createElement
src/game.js           логика игры (без DOM)
src/view.js           шапка, счётчики, поле
src/modal.js          общий компонент модальных окон (<dialog>)
src/screens.js        содержимое окон победы и таблицы лидеров
src/storage.js        localStorage, сортировка, форматирование даты
src/cards.js          список изображений
img/                  изображения карточек (собственные SVG)
tests/                тесты логики и хранилища
scripts/              проверка запрещённых API
```

## Локальный запуск

Нужен Node.js 18+ (для статического сервера и тестов).

```bash
git clone <repo-url>
cd memory-game
git checkout memory-game
npm start
```

Откройте http://localhost:3000.

Не открывайте `index.html` двойным кликом (`file://`): браузер блокирует ES modules. Подойдёт любой статический сервер, например `python3 -m http.server 3000`.

## Скрипты

| Команда         | Что делает                                                            |
| --------------- | --------------------------------------------------------------------- |
| `npm start`     | статический сервер на порту 3000                                      |
| `npm test`      | тесты логики игры и таблицы лидеров (`node:test`)                     |
| `npm run check` | проверка: нет `innerHTML`, `alert` и др., в `<body>` только `<script>` |
